# my-website

Multipage site for Abrar.

- `index.html` — Dynamic landing page (short intro + navigation options)
- `about.html` — About me
- `portfolio.html` — Selected work
- `store.html` — Digital store with working cart

## Local development
Just open `index.html` in a browser, or use a simple server:
```bash
# python
python -m http.server 8000
```

## Workflow with AI (opencode)
- Ask the AI to edit any file
- AI will modify the source directly
- Commit & push (we can do it from here)
- GitHub Pages automatically rebuilds & deploys the live site

## Deploy
GitHub Pages is enabled on the `main` branch, root folder.
